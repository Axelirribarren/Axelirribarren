## &nbsp;Sobre mí

Estudiante de **Analista en Sistemas (3er año, FCyT UADER)** e *indie builder* en partes iguales.
Trabajo en la intersección entre **producto, web moderna e IA aplicada**: llevo ideas hasta
software real, usado por personas reales.

- **Enfoque** — SaaS B2B, plataformas educativas y herramientas con LLMs.
- **Stack central** — Next.js · React · TypeScript · FastAPI · Supabase · PostgreSQL.
- **Criterio** — código que resuelve un problema concreto; cero over-engineering.
- **Hoy** — construyendo **GymOS**, **TUTOR IA** y **Brújula**.
